# Hammam

Information Systems undergraduate at Universitas Lampung focusing on **Linux systems**, **C++ programming**, and **cybersecurity fundamentals**.

---

### Focus Areas
- **Systems & CLI Development** — Building terminal applications and exploring rendering/state mechanics in C++ (`ncurses`) on Arch Linux.
- **Linux & Security Fundamentals** — Practicing command-line workflows, file permissions, networking basics, and wargame challenges (OverTheWire Bandit, Hack The Box).

- **[Snatch-The-Number](https://github.com/RJ-Half/Snatch-The-Number)** — Collaborative 3-person 1st-semester final project: a modular two-player terminal game built in C++ (`ncurses`). Responsible for implementing the terminal rendering, collision detection, and food spawning modules.
- **[cybersecurity-portfolio](https://github.com/hammam-si/cybersecurity-portfolio)** — Documentation, Linux lab writeups, and security fundamentals exercises.
